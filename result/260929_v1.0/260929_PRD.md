# 260929 제품 요구사항 정의서 (PRD) - 공정 추천인 플랫폼 (추천인.com)

## 1. 개요 및 배경 (Background & Goal)
* **서비스명**: 공정 추천인 품앗이 플랫폼 (**추천인.com**)
* **목적**: 
  * 다양한 앱/웹 서비스(토스, 쿠팡, 초코, 애플 등)의 신규 가입자가 추천인 코드를 찾을 때, 특정 인원이 추천 기회를 독점하거나 매크로로 도배하는 문제를 방지.
  * 모든 사용자가 **선입선출(FIFO) 기반의 공평한 큐 회전(Baton Touch)**을 통해 골고루 추천 혜택을 나눌 수 있는 투명한 품앗이 생태계 구축.

---

## 2. 핵심 정책 및 메커니즘 (Core Logic)

### 2.1 공정 대기열 순환 알고리즘 (FIFO Queue & 10분 Lock-Lease)
1. **1순위 노출 원칙**:
   * 각 앱 카테고리 진입 시, 가장 먼저 등록하여 대기 시간이 긴 사용자의 코드가 **[현재 1순위 추천 코드]**로 최상단에 노출됨.
2. **복사 시 즉시 차단 대신 "바통 터치" 적용**:
   * 방문자가 [추천코드 복사하기] 버튼을 누르면:
     1. 클립보드에 코드가 복사됨.
     2. 해당 코드는 즉시 **10분간 쿨다운(매칭/가입 진행 중)** 상태로 전환되고 **대기열 맨 뒤**로 이동.
     3. 대기열 2순위였던 다음 대기자의 코드가 즉시 새로운 **1순위**로 승격되어 다음 방문자에게 노출됨.
   * 효과: 
     * 단순 복사로 인해 영구 삭제되는 피해 방지.
     * 한 사람이 계속 상위에 남아 독점하는 현상 원천 차단.
     * 모든 대기자에게 순서대로 기회가 돌아가는 100% 공정 시스템 실현.
3. **어뷰징 방지 (Anti-Abuse)**:
   * 동일 IP/클라이언트에서 30초 내 연속 복사 시도 제한 (Rate Limiting).
   * 1인당 동일 앱에 추천 코드 중복 등록 방지.

## 3. 기능 명세 (Functional Specifications)

### 3.1 스마트 검색 & 자동완성 (Search & Autocomplete)
* **입력 즉시 반응 (Instant Search)**:
  * 영문 접두사/부분 검색: `a` 입력 시 `Apple` 등 즉시 노출.
  * 한글 음절 검색: `초` 입력 시 `초코` 노출.
  * **한글 초성 검색(Chosung Search)**: `ㅊㅋ` 입력 시 `초코`, `ㅋㄹ` 입력 시 `크림/컬리` 매칭.
* 검색 결과 드롭다운 클릭 시 해당 서비스의 추천인 대기실 카테고리로 스크롤/이동.

### 3.2 카테고리 상세 및 복사 인터페이스 (Category & Copy UX)
* **1순위 추천인 히어로 카드**:
  * 추천인 코드, 등록자 닉네임, 누적 복사 횟수, 혜택 요약 표시.
  * **[원클릭 복사]** 버튼: 클릭 시 클립보드 복사 + 토스트 알림 + 큐 회전 트리거.
  * **[공식 앱/웹 바로가기]** 버튼: 복사 후 바로 가입할 수 있도록 공식 링크 제공.
* **실시간 대기열(Queue) 현황 보드**:
  * 다음에 차례가 올 대기자 명단 및 현재 대기 순번(2위, 3위...), 쿨다운 현황 시각화.
* **신규 추천인 코드 등록 (Join Queue)**:
  * 본인의 추천인 코드를 등록하면 대기열 맨 끝에 줄을 서게 되며 실시간으로 순번 부여.

## 4. 입출력 스펙 (I/O Specification)

### 4.1 검색 API (`GET /api/search?q={query}`)
* **Input**: `query` (string, 예: `a`, `초`, `ㅊㅋ`)
* **Output**:
  ```json
  [
    {
      "id": "choco",
      "name_ko": "초코",
      "name_en": "Choco",
      "category": "라이프스타일",
      "matched_by": "chosung"
    }
  ]
  ```

### 4.2 최우선 추천 코드 조회 API (`GET /api/apps/{app_id}/current`)
* **Input**: `app_id` (string)
* **Output**:
  ```json
  {
    "app": { "id": "choco", "name_ko": "초코", ... },
    "current_top": {
      "id": "ref_choco_1",
      "code": "CHOCO-SWEET-77",
      "nickname": "달콤초코",
      "copy_count": 0,
      "queue_order": 1
    },
    "queue_length": 3,
    "waiting_list": [ ... ]
  }
  ```

### 4.3 복사 및 큐 회전 API (`POST /api/apps/{app_id}/copy`)
* **Input**: `{ "code_id": "ref_choco_1" }`
* **Output**:
  ```json
  {
    "success": true,
    "copied_code": "CHOCO-SWEET-77",
    "next_top": {
      "id": "ref_choco_2",
      "code": "CHOCO-KING-99",
      "nickname": "초코왕자",
      "queue_order": 1
    },
    "message": "코드가 복사되었습니다! 다음 대기자에게 순서가 양도되었습니다."
  }
  ```

### 4.4 신규 코드 등록 API (`POST /api/apps/{app_id}/register`)
* **Input**: `{ "code": "CHOCO-MY-CODE", "nickname": "신규참여자" }`
* **Output**:
  ```json
  {
    "success": true,
    "assigned_order": 4,
    "message": "대기열 4순위에 등록되었습니다."
  }
  ```

## 5. 검증 기준 (Acceptance Criteria)
1. **초성/영문 검색**: `a`, `초`, `ㅊㅋ` 입력 시 100ms 이내에 해당 앱이 자동완성 리스트에 노출되어야 함.
2. **선입선출 회전**: 1순위 코드를 복사했을 때, 즉시 2순위 코드가 1순위로 승격되고 이전 1순위는 대기열 맨 뒤로 밀려나야 함.
3. **클립보드 복사**: 클릭 한 번으로 사용자의 운영체제 클립보드에 코드가 정상 저장되어야 함.
4. **원클릭 재현성**: `run.bat` 실행 시 추가 설치 없이 서비스가 웹 브라우저에서 즉시 정상 구동되어야 함.
