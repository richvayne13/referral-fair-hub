# 260929 최종 구축 및 배포 보고서 - 공정 추천인 플랫폼 (추천인.com)

## 1. 개요
* **프로젝트명**: 공정 추천인 품앗이 플랫폼 (**추천인.com**)
* **작업 버전**: `v1.0` (`tool/260929_v1.0/` ↔ `result/260929_v1.0/`)
* **목적**: 
  * 추천인 코드를 등록하고 찾는 과정에서 발생하는 **최신순 도배, 특정인 독점, 단순 복사로 인한 코드 유실**을 방지하고, 모든 참여자가 100% 공평하게 혜택을 나누는 **선입선출(FIFO) 바통 터치 분배 시스템** 구축.

---

## 2. 핵심 질문 해결 및 정책 결정 내용

### 질문: *"마지막에 등록한 사람의 추천인 코드를 복사하는 순간 그 코드를 복사 못하게 막는 게 좋을까? 아니면 어떤 방법이 나을까?"*

### 결정 및 구현 내용: **"선입선출 회전 큐 + 10분 쿨다운 바통 터치(Baton Touch)" 방식 적용**
1. **단순 즉시 차단 방식의 폐기 이유:**
   * 단순 복사 후 실제 미가입 시 등록자의 코드가 억울하게 증발함.
   * 악의적인 매크로나 광클 공격 시 수초 만에 사이트 내 모든 코드가 전멸함.
   * 최신순 노출 시 상위 노출을 노린 끊임없는 재등록 도배가 발생함.
2. **구현된 공정 메커니즘:**
   * **1순위 노출**: 대기열에서 가장 오래 기다린 사람의 코드가 1순위로 최상단 노출.
   * **바통 터치 회전**: 방문자가 [복사하기]를 누르는 즉시 해당 코드는 클립보드에 복사되고, **10분 쿨다운과 함께 대기열 맨 뒤로 자동 이동**.
   * **차순위자 자동 승격**: 대기열 2순위였던 사람이 즉시 1순위로 승격되어 다음 방문자에게 노출됨.
   * **참여 보장**: 신규 등록자는 대기열 맨 뒤에 줄을 서며 앞 순번이 복사될 때마다 순번이 앞으로 당겨짐.

## 3. 구축된 핵심 기능

### 3.1 스마트 검색 및 자동완성 엔진 (`search_engine.py`)
* **영문 검색**: `a` 입력 시 `Apple` 등 접두사 및 포함 단어 매칭.
* **한글 음절 검색**: `초` 입력 시 `초코` 매칭.
* **한글 초성 분해 검색(Chosung Search)**: 유니코드 자모 분해를 통해 `ㅊㅋ` 검색 시 `초코`, `ㅋㄹ` 검색 시 `크림/컬리` 즉시 추천.
* **실시간 드롭다운 UI**: 타이핑 즉시 연관 서비스와 현재 대기자 수 카드 표시.

### 3.2 카테고리 상세 및 복사 인터페이스 (`index.html`)
* **1순위 추천인 히어로 배너**: 현재 복사 대상 코드, 닉네임, 누적 복사 횟수, 혜택 안내 표시.
* **원클릭 복사**: 클릭 즉시 OS 클립보드 복사 + 서버 큐 회전 + 토스트 피드백.
* **공식 앱 바로가기**: 딥링크를 통해 복사 후 즉시 가입/설치 페이지로 이동 지원.
* **실시간 대기열 현황판**: 다음에 차례가 올 대기자 명단(닉네임 마스킹) 및 대기 순번 투명 공개.
* **내 코드 등록 폼**: 서비스 선택 후 본인 추천코드 등록 시 실시간으로 대기 순번 발급.

## 5. 실행 방법 (원클릭 재현성)

1. **실행 방법**:
   * `C:\업무\260929_추천인플랫폼\run.bat` (또는 `tool/260929_v1.0/run.bat`) 파일을 더블클릭합니다.
2. **동작**:
   * 파이썬 내장 경량 서버가 포트 `8080`에서 즉시 시작됩니다.
   * 기본 웹 브라우저가 자동으로 실행되며 `http://localhost:8080`으로 접속됩니다.
3. **사용 흐름**:
   * 검색창에 `초` 또는 `a` 또는 `ㅊㅋ`를 입력해 자동완성 드롭다운을 확인합니다.
   * `초코`를 클릭해 대기실로 이동한 뒤, 1순위 추천코드를 **[원클릭 복사]**합니다.
   * 복사 즉시 다음 대기자가 1위로 승격되고 이전 1위는 대기열 맨 뒤로 회전하는 것을 실시간으로 확인할 수 있습니다.
